# Redirection de l'ancienne adresse

Contenu du dépôt **`stats-basket`** à recréer après avoir renommé le dépôt de l'appli en `pickstats` :
l'ancienne adresse `slunox.github.io/stats-basket/…` renvoie vers `slunox.github.io/pickstats/…`,
en gardant la suite de l'adresse (`demo.html`, `?demo`, `#m=…` des matchs partagés).

- `index.html` : l'adresse de l'appli elle-même ;
- `404.html` : toutes les autres pages (GitHub Pages l'affiche pour une page qui n'existe pas).

Ce dossier ne sert à rien dans le dépôt de l'appli : il est là pour être copié.
